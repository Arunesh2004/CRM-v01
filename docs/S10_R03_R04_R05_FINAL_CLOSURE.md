## 3. R03 Implementation
The ingestion daemon was hardening by enforcing the tenant context globally for writes.
- **Tenant Context (`withScopedTenantContext`)**: Uses `$executeRaw` to safely run `SELECT set_config('app.current_tenant_id', ${tenantId}, true)`. This parameterization complies with the S2 standard.
- **Atomicity**: The context is set and cleared on the same transaction connection `tx` before any tenant-scoped operations, averting any nested Prisma client issues.

## 4. R03 Security Evidence
- Verified via `cctv-ingestion-daemon.test.ts`.
- Valid tenant paths succeed. Forged opaque paths strictly fail due to `tenantId` mismatch inside the database RLS policies.
- **Classification**: SAFE.

## 5. R04 Implementation
JWT transmission moved out of the URL query string (where it leaks in browser history and server logs).
- **Next.js WHEP Proxy**: Created at `src/app/api/cctv/cameras/[id]/whep/route.ts`.
- **Flow**: Browser sends `Authorization: Bearer <JWT>` -> WHEP Proxy -> Internal MediaMTX (using `?token=` internally as per its config contract).

## 6. R04 Security Evidence
- Verified via `cctv-stream-integration.test.ts`.
- Missing/invalid/expired Authorization headers correctly fail with 401/403.

## 7. R05 Implementation

- **Implementation**: The webhook at `src/app/api/webhooks/mediamtx/auth/route.ts` exclusively checks `Authorization: Bearer <secret>`.
